# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| Latest release on `main` | :white_check_mark: |
| Earlier versions | :x: |

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions, or pull requests.

Use the repository's private security-advisory flow instead: [report a vulnerability](https://github.com/SharpSplinter/Naughty-Faction-Companion/security/advisories/new). Include a clear description, affected script version, reproduction steps, likely impact, and a safe proof of concept when possible.

Do not include Torn API keys, FFScouter-linked keys, target lists, member data, complete backups, or unredacted exports. A maintainer will aim to acknowledge a valid report within seven days and will coordinate a fix and disclosure timeline with the reporter.

## Scope

This policy covers this repository's userscript, local storage adapter, JSON/CSV export handling, TornPDA bridge use, Torn API requests, and FFScouter integration behavior. It does not cover Torn, Tampermonkey, TornPDA, FFScouter, GitHub, or third-party services themselves, though reports about unsafe integration behavior are welcome.

There is no bug-bounty program. Good-faith research that avoids privacy harm, service disruption, and access to other players' data is appreciated.
